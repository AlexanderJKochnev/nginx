# Настройка 3: Защитите SSH отдельно (не через Fail2ban)

# Отключите вход по паролю (используйте только ключи):

sudo nano /etc/ssh/sshd_config
PasswordAuthentication no
PermitRootLogin prohibit-password

# Измените порт SSH (на 2222 или другой):
Port 2222


# Используйте knockd (скрытый доступ через стук портов).
Port Knocking — это метод "скрытого" открытия порта. 
Вы заранее задаете секретную последовательность портов (например, 7000, 8000, 9000). 
Когда вы "стучите" в эти порты в правильном порядке, 
сервер временно открывает SSH-порт специально для вашего IP-адреса. 
Если последовательность неправильная — порт остается закрытым, и сканеры его не видят.

# ------
1. SSH-ключи + отключение паролей	Базовый уровень	Перебор паролей бесполезен 
2. Смена порта	Первичная фильтрация	Отсекает 90% автоматических сканеров 
3. Port Knocking (knockd)	Скрытие порта	Порт не виден сканерам вообще 
4. Fail2ban	Реактивная защита	Блокирует тех, кто пытается ломиться 
5. Ограничение попыток через iptables	Проактивная защита	Лимит подключений с IP
